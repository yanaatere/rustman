  proven cause of the still-failing automated loopback fixture.
- HTTP fixture is intentionally unencrypted localhost traffic with fake values.
  No HTTPS/MITM/invalid-cert/proxy-trust runtime validation occurred. AES at rest
  does not encrypt HTTP on the wire.
- Auto suite latest combined checkpoint still 12 passed/1 loopback failure; no
  claim of all automated checks passing. Cross-platform, crash/locked-file cleanup,
